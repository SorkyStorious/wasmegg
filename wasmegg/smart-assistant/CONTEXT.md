# Smart Assistant

A personalized recommender: optimal prestige artifact loadouts and a planner for the Soul/Prophecy Eggs needed to hit Earning Bonus targets.

> Read the root [`CONTEXT.md`](../../CONTEXT.md) first — Earning Bonus, Farmer Role, Loadout, Boost, Prestige, Soul/Prophecy Egg, and Epic Research are defined there. This file adds only Smart Assistant terms.

## Language

**Naked**:
An Earning Bonus (or stat) computed without any artifact effects — the base from Soul Eggs, Prophecy Eggs, Truth Eggs, and epic research alone.
_Avoid_: bare, unmodified, base EB

**Soul Food level**:
The epic research (0–150) that adds soul-egg bonus per level; an input to the earning-bonus planner.

**Prophecy Bonus level**:
The epic research (0–5) that adds prophecy-egg bonus per level; an input to the earning-bonus planner.

**Dilithium stone holder**:
An artifact (usually a 3-slot legendary) reserved to carry high-rarity dilithium stones, maximizing boost duration before a prestige.

**Multi-prestige**:
A strategy running several prestiges inside one 10-minute boost window, for high-Earning-Bonus players.
_Avoid_: multi-stige

**Preload**:
A strategy that pre-fills habs with artifact boosts before activating boost beacons, leaving little hab space for RCB to build.

**All-in-one**:
A single-prestige strategy using the multi-prestige boost set but only one prestige session.

**Lunar-prestige**:
A variant where the player equips away-earnings artifacts and goes offline instead of running chickens.
_Avoid_: lunar-stige

**Book of Basan**:
A rare upgradeable artifact that carries prophecy/soul stones and directly boosts Soul and Prophecy Egg values when equipped.
