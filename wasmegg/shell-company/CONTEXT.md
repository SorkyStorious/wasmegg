# Shell Company

A personal, always-current catalog of cosmetic items — shells, shell sets, hats, chickens, decorators — with ownership and pricing.

> Read the root [`CONTEXT.md`](../../CONTEXT.md) first for the shared game language. Cosmetics are this tool's own domain; all terms below are unique to it.

## Language

**Shell**:
A cosmetic skin for a farm building (hab, silo, depot, coop, lab, mailbox, fuel tank, mission control, hyperloop station, etc.).
_Avoid_: skin, theme (for buildings)

**Shell Set**:
A themed collection of shells — typically one per building type — often discounted when bought complete.
_Avoid_: bundle, pack

**Variation**:
A color/appearance option for a shell or shell set, priced separately; default variations come with the set.
_Avoid_: colorway, style

**Decorator**:
A standalone cosmetic bundle that is simply owned or not — no pieces or variations.

**Chicken Skin**:
A cosmetic appearance for the farm's chickens.
_Avoid_: chicken (bare — means the animal/count elsewhere)

**Hat**:
A cosmetic hat worn by chickens.

**Shell Script**:
The currency for all cosmetics; tracked as earned, spent, and balance.
_Avoid_: ticket, token

**Exclusivity**:
Whether a cosmetic is limited-time ("exclusive") or permanent.
