# Legendary Study Report

Rolling 30-day population statistics on legendary-artifact ownership across the player base, for benchmarking your own collection.

> Read the root [`CONTEXT.md`](../../CONTEXT.md) first — Artifact, Rarity (Legendary), and Mission are defined there. This file adds only Legendary Study terms.

## Language

**Rolling report**:
A continuously-updated 30-day population snapshot of artifact-ownership trends, rather than a point-in-time capture.

**Enrollment**:
Voluntary opt-in (via Rockets Tracker) to contribute anonymized backup data to the study dataset.
_Avoid_: signup, registration

**Selection bias**:
The acknowledged caveat that participants are self-selected avid players, so the population isn't representative of all players.

**Legendaries seen**:
A rarity metric — how many enrolled players own each specific legendary, shown as "1 per X players".

**Possessed legendaries**:
The distribution of how many legendaries individual players own, given as percentile ranks within the enrolled population.

**Zero Legendary Club**:
The cohort of enrolled players with zero legendaries; the report highlights the max extended-Henerprise/Henliner count any such player reached. Abbreviated ZLC.
