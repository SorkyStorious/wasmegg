# Virtue Companion

A progress report for the Ascension (Virtue) mode: time to the next Truth Egg threshold, current TE earned/pending, and the farm metrics that drive Virtue Egg delivery.

> Read the root [`CONTEXT.md`](../../CONTEXT.md) first — Ascension, Virtue Egg, Shift, Shift Count, Truth Egg, Clothed TE, and Running Chicken Bonus are defined there. This file adds only Virtue Companion terms.

## Language

**TE threshold**:
A fixed lifetime-shipped quantity that, once a Virtue Egg reaches it, awards one Truth Egg. Discovering a threshold reveals it for all Virtue Eggs.
_Avoid_: breakpoint, milestone

**Relative progress**:
A display mode showing progress as the percentage between the previous and next TE threshold, rather than from zero.

> Note: the backup's `eovEarned` ("eggs of virtue earned") field is the player's **Truth Eggs**, not a separate count — see Truth Egg in root.
