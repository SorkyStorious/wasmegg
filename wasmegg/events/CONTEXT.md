# Events Calendar

A filterable calendar of in-game events (sales, boosts, drop buffs, and the like).

> Read the root [`CONTEXT.md`](../../CONTEXT.md) first for the shared game language. This file adds only Events terms.

## Language

**Event**:
A time-boxed in-game promotion that temporarily changes a game parameter (e.g. cheaper research, boosted drops, faster missions).
_Avoid_: promo, sale (sale is one kind of event)

**Ultra**:
A flag marking an enhanced or extended variant of an event (e.g. an ultra boost event).
_Avoid_: mega, super
