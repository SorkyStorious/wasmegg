# Past Contracts Viewer

A history of a player's contract attempts plus a Prophecy Egg completion tracker across all sources.

> Read the root [`CONTEXT.md`](../../CONTEXT.md) first — Contract, Co-op, Leggacy, Grade, League, and Prophecy Egg are defined there. This file adds only Past Contracts terms.

## Language

**Teamwork Score**:
A metric of a player's relative contribution to a co-op contract, computed at contract evaluation.
_Avoid_: contribution score, participation score

> A re-run of a contract is a **Leggacy** (see root) — not an "incarnation". Use Leggacy.
