# Consumption Sheet

A table of the outcomes of consuming artifacts — the rewards and byproducts you get back.

> Read the root [`CONTEXT.md`](../../CONTEXT.md) first — Artifact, Rarity, Stone, and Golden Egg are defined there. This file adds only Consumption Sheet terms.

## Language

**Consumption**:
Sacrificing an artifact, stone, or ingredient for a return (Golden Eggs, fragments, or other items).
_Avoid_: scrapping, selling

**Demotion**:
A consumption outcome that drops an artifact down a rarity, paying out Golden Eggs.
_Avoid_: downgrade

**Byproduct**:
A secondary item returned alongside the main reward of a consumption.
_Avoid_: bonus, extra
